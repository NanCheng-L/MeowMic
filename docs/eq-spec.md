# MeowMic 可视化均衡器 — 功能规格

> 参考 SteelSeries GG Sonar 麦克风 EQ 设计
> 创建日期：2026-06-14

---

## 一、整体架构

### 1.1 组件定位
- 独立窗口（WebviewWindow），主界面通过按钮打开
- 可独立抽出为通用 Vue 组件（vue-eq-canvas），发布到 GitHub/npm
- 技术栈：Vue 3 + TypeScript + Canvas 2D

### 1.2 数据流
```
用户操作 UI → 更新 bands[] → 调用 Rust Tauri command → 音频引擎实时应用 EQ
                                         ↓
                                  同步绘制 Canvas 曲线
```

### 1.3 音频管线位置
```
麦克风采集 → 重采样 → 降噪 → 强度混合 → 麦克风增益 → 【EQ 均衡器】→ 爆炸模式 → BGM 混音 → 软限制 → 输出
```
- EQ 在降噪**之后**、增益**之后**、爆炸模式**之前**
- 降噪处理原始信号，EQ 调整降噪后的音色，互不干扰
- 增益放在 EQ 之前，确保 EQ boost 不会导致削波

### 1.4 Rust 后端支持
- 当前：10 段 Peaking EQ（biquad IIR 滤波器）
- 未来扩展：High Pass / Low Pass / Low Shelving / High Shelving / Notch Filter
- 每个频段参数：增益(dB) + 频率(Hz) + Q 值

## 三、功能模块

### 3.1 顶部栏

| 元素 | 功能 |
|------|------|
| 开关 Toggle | 启用/禁用 EQ，蓝色 = 启用 |
| 「均衡器」标题 | 纯展示 |
| 「?」帮助按钮 | 悬停/点击显示功能说明 tooltip |
| 「⋮」三点菜单 | 仅「重置」：重置所有频段为默认值 |

#### 帮助提示框内容
```
调整频率、增益和Q因子，精确无误地塑造声音。
添加和移除多达10个单独频段，使用内置
滑块轻松调节低频、语音和高音频频率。
```
- 样式：深色半透明背景 + 圆角，位于标题下方
- 触发：悬停或点击问号按钮
- 消失：鼠标移出或点击其他区域

### 3.2 频段分类标签

#### 默认模式（Default）
| 标签 | 频率范围 | 说明 |
|------|----------|------|
| SUB BASS | 20-60 Hz | 次低频隆隆声 |
| BASS | 60-250 Hz | 低频厚度 |
| LOW MIDS | 250-500 Hz | 温暖感/浑浊 |
| MID RANGE | 500Hz-2 kHz | 人声主体 |
| UPPER MIDS | 2-6 kHz | 清晰度/存在感 |
| HIGHS | 6-20 kHz | 空气感/齿音 |

#### 语音模式（Voice）
| 标签 | 频率范围 | 说明 |
|------|----------|------|
| LOW END RUMBLES | 20-80 Hz | 低频隆隆 |
| CORE VOICE | 80-400 Hz | 人声核心 |
| BOX | 400-800 Hz | 箱体共鸣 |
| MID RANGE | 800Hz-3 kHz | 中频 |
| SIBILANCE | 3-8 kHz | 齿音 |
| AIR | 8-20 kHz | 空气感 |

#### 交互
- 标签行右侧有下拉箭头 ▼，切换 Default / Voice 模式
- 点击某个标签时，图表区域高亮对应频段范围（半透明覆盖层）
- 标签之间有竖线分隔

### 3.3 Canvas 图表区

#### 坐标系
- X 轴：对数频率刻度，20Hz ~ 20kHz
- Y 轴：线性 dB 刻度，-12 dB ~ +12 dB

#### 网格线
- 水平线：-12, -6, 0, +6, +12 dB（0dB 线略亮）
- 垂直线（详细对数刻度）：
  - 20-100Hz：每 10Hz 一条（20/30/40/50/60/70/80/90/100）
  - 100Hz-1kHz：每 100Hz 一条（100/200/300/.../1000）
  - 1kHz-10kHz：每 1kHz 一条（1k/2k/3k/.../10k）
  - 10kHz-20kHz：直接到 20k
- 主刻度（有标签）：20Hz / 50Hz / 100Hz / 200Hz / 500Hz / 1kHz / 2kHz / 5kHz / 10kHz / 20kHz
- 次刻度：无标签，线条更细（0.4px vs 0.8px）
- 样式：主刻度 `rgba(255,255,255,0.1)`，次刻度同色
- 频率标签：底部，白色 50% 透明度

#### 频率响应曲线
- 白色平滑曲线，宽度 1.5px
- 曲线下方：半透明渐变填充（上 8% 透明 → 下 0% 透明）
- 采样 400 点，贝塞尔插值平滑

#### 10 个频段圆点
| 频段 | 中心频率 | 颜色 |
|------|----------|------|
| 1 | 31 Hz | `#a78bfa` 紫色 |
| 2 | 62 Hz | `#f472b6` 粉色 |
| 3 | 125 Hz | `#fb7185` 玫红 |
| 4 | 250 Hz | `#f97316` 橙色 |
| 5 | 500 Hz | `#eab308` 黄色 |
| 6 | 1 kHz | `#84cc16` 黄绿 |
| 7 | 2 kHz | `#22c55e` 绿色 |
| 8 | 4 kHz | `#14b8a6` 青色 |
| 9 | 8 kHz | `#06b6d4` 天蓝 |
| 10 | 16 kHz | `#60a5fa` 蓝色 |

#### 圆点样式
- 默认：直径 10px，实心填充 + 1px 白色半透明边框
- 外圈光晕：16px 半透明同色（opacity 20%）
- 悬停：放大到 12px，光晕增强
- 拖拽中：放大到 14px，光晕最强
- **Q 值控制把手**：主圆点两侧各有一个小圆点（直径 6px），通过水平线连接
  - 把手向内收窄 = Q 值增大（曲线更尖锐）
  - 把手向外展开 = Q 值减小（曲线更平缓）
  - Q 值范围：0.5 ~ 10.0
  - 默认 Q 值：0.707（Butterworth）
  - 把手颜色与主圆点相同

### 3.4 鼠标交互

#### 悬停（Hover）
- 鼠标移入圆点范围（20px 碰撞检测）
- 显示浮动 tooltip，内容见 3.5
- 圆点放大 + 光晕增强
- 显示该频段颜色的独立曲线
- 显示 Q 值控制把手（两侧小圆点 + 水平连接线）
- 鼠标移出：tooltip 消失，圆点恢复，把手和独立曲线隐藏

#### 点击（Click）
- 点击圆点：tooltip 固定显示，可编辑
- 点击空白处：tooltip 消失
- 超时 5 秒无操作：tooltip 自动消失

#### 拖拽（Drag）
- **垂直拖拽主圆点**：调整增益（-12 ~ +12 dB，snap to 0.5）
- **水平拖拽主圆点**：调整频率（对数刻度）
- **拖拽两侧把手**：调整 Q 值（0.5 ~ 10.0），把手间距越小 Q 越大
- 拖拽/选中时同时显示：
  - 白色总响应曲线（实时更新）
  - 该频段颜色的独立曲线（展示单频段影响）
- 松开鼠标：拖拽结束，独立曲线消失

#### 右键菜单（Context Menu）
- 右键点击圆点：弹出上下文菜单
  - **重置**：该频段恢复默认值（0 dB，原始频率）
  - **删除**：隐藏该频段圆点（禁用该频段），可从曲线上的 + 号重新添加

#### 添加节点（Add Node）
- 当节点被删除后，鼠标悬停白色响应曲线上
- 鼠标变为十字，曲线位置显示 **+ 号白色小圆点**（直径 12px）
- 点击 + 号：在该频率位置添加新节点
- 新节点继承该位置曲线上的 dB 值作为初始增益
- **颜色回收**：被删除节点的颜色进入回收池，按删除顺序依次复用
  - 例：删除紫色(1号) → 粉色(2号)，添加第一个新节点 = 紫色，第二个 = 粉色
  - 回收池为空时，从颜色池末尾开始循环

#### 频率显示格式
- `< 1kHz`：显示 `xxx.x Hz`（如 `31.0 Hz`）
- `≥ 1kHz`：显示 `x.x kHz`（如 `1.1 kHz`）
- 所有数值保留 1 位小数
- X 轴频率标签：`20Hz` / `50Hz` / `100Hz` / `200Hz` / `500Hz` / `1kHz` / `2kHz` / `5kHz` / `10kHz` / `20kHz`

### 3.5 信息弹窗（Tooltip / Popup）

#### 悬停态（临时显示）
```
┌────────────────────────────────┐
│ 🟣 Enabled        ∩ Peaking EQ │
│ [0.2 dB]   [38.0 Hz]   [0.707] │
│  增益        Freq         Q     │
└────────────────────────────────┘
```

#### 固定态（点击后）
- 同上，但不自动消失
- 数值输入框可编辑：
  - 点击输入框：单位隐藏，只显示纯数字，全选
  - 只接受数字（禁止字母、符号）
  - 频率最小 20
  - 按回车或点击其他地方：确认输入，单位恢复显示，节点跳转到对应位置
- 右上角滤波器类型可点击切换

#### 信息框元素

| 元素 | 功能 |
|------|------|
| 彩色圆点 | 显示当前频段颜色 |
| Enabled 开关 | 启用/禁用该频段 |
| 滤波器类型 | 显示当前类型 + 点击切换下拉菜单 |
| 增益输入框 | 数值显示 `x.x dB`，点击编辑时隐藏单位只显示数字，按回车确认后恢复单位 |
| 频率输入框 | 数值显示 `xxx.x Hz` 或 `x.x kHz`（保留 1 位小数），点击编辑时隐藏单位只显示数字，按回车确认后恢复单位 |
| Q 值输入框 | 数值显示 `0.xxx`（保留 3 位小数），点击编辑时直接可编辑，按回车确认 |

#### 滤波器类型下拉菜单
- 点击信息框右上角的滤波器类型区域
- 弹出下拉列表：
  - **High Pass**（高通）：低频截止，曲线向左下方跌落
  - **Low Pass**（低通）：高频截止，曲线向右下方跌落
  - **Peaking EQ**（峰值均衡）：标准钟形曲线，Q 控制宽度 ← 当前使用
  - **Notch Filter**（陷波）：深 V 型切除，Q 控制深度
  - **Low Shelving**（低频搁架）：低频整体提升/衰减，Q 控制斜率宽度
  - **High Shelving**（高频搁架）：高频整体提升/衰减，与 Low Shelving 镜像
- 选择后：曲线形状变化 + 后端切换滤波器系数
- 每种类型有独立的曲线图标（∩ / ∪ / ⌢ / ⌣ 等）

#### 三点菜单
- 右上角 ⋮ 按钮，点击展开菜单
- 仅包含「重置」选项：重置所有频段为默认值（等同底部重置按钮）

### 3.6 预设系统

#### 内置预设
| 预设名 | 说明 | 曲线特征 |
|--------|------|----------|
| Flat | 平坦 | 所有频段 0 dB |
| Clear | 清晰人声 | 提升 2-4kHz，衰减 250Hz |
| Warm | 温暖 | 提升 125-250Hz，衰减 8kHz+ |
| Broadcast | 广播级 | V 型曲线，低频+高频提升 |
| Bass Boost | 低音增强 | 大幅提升 62-250Hz |
| Treble Boost | 高音增强 | 提升 4-16kHz |
| Podcast | 播客 | 提升 1-4kHz 人声核心，衰减低频 |

#### 预设切换
- 顶部标签栏右侧下拉菜单切换
- 切换时所有圆点 + 曲线平滑动画过渡

## 六、独立组件化目标（vue-eq-canvas）

### 6.1 组件 API 设计
```vue
<EqCanvas
  v-model="bands"
  :frequencies="[31, 62, 125, 250, 500, 1000, 2000, 4000, 8000, 16000]"
  :colors="['#a78bfa', ...]"
  :min-db="-12"
  :max-db="12"
  :sample-rate="48000"
  :filter-types="['peaking', 'highpass', 'lowpass']"
  @band-change="(index, band) => {...}"
  @drag-start="(index) => {...}"
  @drag-end="(index) => {...}"
/>
```

### 6.2 依赖
- Vue 3 + Composition API
- 无第三方依赖（纯 Canvas 绑定）

### 6.3 可配置项
- 频段数量和频率
- 颜色方案
- dB 范围
- 滤波器类型列表
- 是否显示频段分类标签
- 是否显示预设选择器
- 主题（dark/light）

### 6.4 多语言与主题注意事项
> **重要**：新增弹窗/独立窗口组件时，必须考虑以下事项：

#### 多语言同步
- 独立窗口必须在 `onMounted` 时从 `localStorage` 读取语言设置并调用 `setLocale()`
- 添加 `setInterval` 轮询 `localStorage` 的 `meowmic-lang` 键，实时同步语言变化
- 添加 `storage` 事件监听器，跨窗口同步语言变更
- 所有用户可见文本必须使用 `t('key')` 函数，不能硬编码

#### 主题同步
- 使用 `useTheme()` composable 获取当前主题
- Canvas 绘制的颜色必须根据主题动态切换（通过 `getThemeColors()` 函数）
- 监听 `theme` 变化，变化时重绘 Canvas
- CSS 使用 `var(--bg)` / `var(--surface)` / `var(--border)` 等主题变量

#### 窗口生命周期
- 使用 `WebviewWindow.getByLabel()` 检查窗口是否已存在，避免重复创建
- 窗口关闭用 `hide()` 代替 `close()` 避免 label 无法释放
- `capabilities/default.json` 中必须添加窗口名到 `windows` 数组

#### 代码组织
- 入口文件（如 `eq-main.ts`）必须导入 `main.css` 和 i18n
- HTML 文件（如 `eq.html`）必须包含 Google Fonts 链接
- `vite.config.ts` 的 `rollupOptions.input` 必须添加新入口
